# الأمان

التطبيقان تجريبيان. أي نتيجة موقعة تحمل `mode=DEMO` و`settled=false`. تصلح هذه النتيجة لإثبات اكتمال التجربة المحلية فقط.

ينشئ كل تطبيق مفتاح ECDSA P-256 في Android Keystore. ينسخ المستخدم مفتاحه العام بصيغة SPKI DER مرمزة Base64، ويستورد كل طرف مفتاح الآخر من قناة مستقلة موثوقة. تحتفظ النسخة بمفتاح مقابل واحد. إقران مفتاح آخر قد يتطلب إعادة إقران الجهاز القديم لاسترجاع معاملاته المفتوحة.

يتضمن غلاف الفاتورة أو النتيجة حقلَي `body` و`signature` بترميز Base64 عادي بلا التفاف. يوقع المرسل وحدات UTF-8 الأصلية لـ JSON الداخلي باستخدام `SHA256withECDSA` وتوقيع DER. يتحقق المستقبل من التوقيع على البايتات المستلمة قبل تفسير الحقول، دون إعادة ترتيب خصائص JSON. يوقّع القارئ أوامر التحكم على UTF-8 للنص `GNPP-1-control` متبوعًا ببايت INS ثم UUID الثنائي. تسمح الأوامر باسترجاع النتيجة أو تأكيدها تكرارًا لنفس المعاملة.

التحقق يربط القرار بمعرّف المعاملة والفاتورة والمبلغ والعملة، ويحفظ نتيجة نهائية واحدة. يمنع تكرار المعرّف بصيغة مختلفة وتكرار Nonce. بصمة SHA-256 تفحص سلامة تجميع الأجزاء. المفاتيح العامة تُوثّق بإجراء الربط اليدوي. الحماية من ترحيل NFC أو اعتراض البيانات وتشفير الجلسة والتدوير المنظم للمفاتيح خارج هذه النسخة. حافظ على تقارب ساعات الجهازين.
