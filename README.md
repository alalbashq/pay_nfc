# نقطة بيع غله وغله باي

نموذج أولي للدفع التجريبي بين جوالين Android بواسطة NFC مباشر. ينشئ **نقطة بيع غله** فاتورة ويرسلها، ويعرض **غله باي** تفاصيلها وزري القبول والرفض. تحفظ قاعدة SQLite قرار العميل قبل استرجاعه عبر NFC. لا يوجد خصم مالي أو تكامل مع ERPNext.

## التشغيل

واجهتا نقطة بيع غله وغله باي مبنيتان بـ Vue 3 وتعملان داخل Capacitor على Android. يبقى بروتوكول GNPP وقارئ NFC وخدمة HCE وتخزين SQLite والمفاتيح في طبقة Android الأصلية.

من جذر المشروع، استخدم Node.js 22 وثبّت الحزم بـ `npm ci`. للمعاينة في المتصفح شغّل `npm run dev:pos` أو `npm run dev:pay`. المعاينة تعرض الواجهة والإعدادات ولا تنفّذ معاملات NFC. لبناء التطبيقين، استخدم أمر Gradle في [دليل التثبيت](docs/INSTALLATION.md). يبني Gradle واجهتي Vue ويضمّنهما في ملفَي APK تلقائيًا.

1. ابنِ وثبّت تطبيقَي Debug على جهازين وفق [دليل التثبيت](docs/INSTALLATION.md).
2. افتح الإعدادات في كلا التطبيقين. انسخ رمز كل جهاز وانقله عبر قناة تثق بها إلى حقل الجهاز المقابل في التطبيق الآخر. احفظ الربط في الطرفين.
3. فعّل NFC على الجهازين. افتح غله باي واضغط «تفعيل استقبال الدفع».
4. أنشئ فاتورة في نقطة بيع غله واضغط «إرسال طلب الدفع». قرّب الجهازين حتى يظهر طلب الدفع.
5. اقبل الطلب أو ارفضه في غله باي. أبقِ الجهازين متقاربين أو أعد التقريب لإرسال القرار.
6. بعد إغلاق التطبيق، افتح العملية من سجل نقطة البيع لاستئنافها بنفس المعرّف.
